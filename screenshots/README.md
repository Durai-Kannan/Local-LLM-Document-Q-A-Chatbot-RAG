# Task 2 Screenshots Guide

This directory holds visual demonstration screenshots of the **Local LLM Document Q&A Chatbot (Task 2)**.

## Required Screenshot Checklist

1. **`01_document_upload.png`**: Interface showing document drag & drop uploader with ingestion progress.
2. **`02_chat_interface.png`**: Active Q&A session displaying user question and grounded LLM answer.
3. **`03_source_citations.png`**: Inspection modal displaying exact document title, page number, similarity score, and chunk snippet.
4. **`04_api_health.png`**: Browser JSON response of `GET /api/health` demonstrating system status.
5. **`05_ollama_status.png`**: Terminal window showing `ollama list` output verifying local execution.
